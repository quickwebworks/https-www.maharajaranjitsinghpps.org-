# Maharaja Ranjit Singh Police Public School

Modern responsive school website with locally hosted Manrope fonts, a three-slide homepage carousel that advances every 3 seconds, and a searchable event gallery with photo viewer.

## Preview locally

Run `python3 -m http.server 8000 --directory dist`, then open http://localhost:8000.

## Deploy

Upload the contents of `dist/` to your web hosting public directory. No build step or database is required.

School admission, payment, login and disclosure links lead to the existing school services. Event images are sourced from the school's original website.
